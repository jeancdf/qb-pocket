# Player model

`football-athlete.glb` is the skinned Soldier model distributed with the
Three.js examples. The model originates from Mixamo and includes idle, walk,
and run animation clips.

Source:
https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/Soldier.glb

The model is bundled locally so gameplay does not depend on a third-party
network request.
